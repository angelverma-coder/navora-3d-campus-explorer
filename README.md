# Navora — 3D Campus Explorer

A desktop application designed to make campus exploration and location discovery more interactive.

## Overview

Navora provides a 3D campus view where users can explore academic blocks, search for locations, view available building information, and follow walking directions.

## Features

- 3D campus visualization
- Search for campus locations and listed rooms
- Academic block information and photographs
- Walking route calculation and step-by-step directions
- Interactive camera controls for rotation and zoom

## Tech Stack

- Java
- JavaFX
- Maven

## Getting Started

### Prerequisites

- A compatible Java JDK
- Maven
- An internet connection for downloading dependencies on the first build

### Run the project

1. Clone or download this repository.
2. Open the project directory in a terminal.
3. Run:

   `mvn clean javafx:run`

You may need to configure Java and Maven for your operating system.

## Project Structure

- `pom.xml` — Maven configuration and dependencies
- `src/main/java/` — Java source code
- `src/main/resources/photos/` — campus building photographs
